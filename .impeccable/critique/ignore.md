# Critique ignore list

Findings matching these are dropped from critique reports (owner's decision, Nov 2026).

- Years-of-experience wording that differs between "10 years" and "9+ years" (site, meta tags, LinkedIn).
- Project naming differences between the site, resume and GitHub (for example "Datastream" vs "Datasource" Intelligence).
- Naming of clients (Payliance, Dentsu, etc.): client names may be used wherever required; do not flag NDA or naming consistency.
